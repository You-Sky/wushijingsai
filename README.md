# 五史知识竞赛题库

面向五史知识竞赛的个人备考网站，基于 React + TypeScript + Vite 开发。仓库包含**初赛题库（400题）**和**决赛综合训练题库终稿（1000题）**两套独立网站，均通过 GitHub Pages 公开发布，无需注册学习账号。

## 在线使用

| 版本 | 题量 | 访问入口 |
| --- | ---: | --- |
| 初赛题库 | 400 | [进入初赛题库](https://you-sky.github.io/wushijingsai/) |
| 决赛综合训练题库（终稿） | 1000 | [进入决赛题库](https://you-sky.github.io/wushijingsai/finals/) |

两个网站共用本仓库，但题库和学习记录独立保存，初赛的原有记录不受决赛版影响。电脑和手机浏览器均可使用。

## 题库内容

| 类别 | 初赛 | 决赛终稿 |
| --- | ---: | ---: |
| 单选题 | 200 | 500 |
| 多选题 | 100 | 250 |
| 判断题 | 100 | 0 |
| 填空题 | 0 | 250 |
| 总计 | 400 | 1000 |

两套题库均分为党史、新中国史、改革开放史、社会主义发展史、中华民族发展史（决赛原文称“中华民族史”）五大板块。初赛每板块80题（单选40、多选20、判断20），决赛每板块200题（单选100、多选50、填空50）。

- **初赛来源**：《五史知识竞赛题库_word最终版.docx》，原始题号1—400。
- **决赛来源**：《五史题终稿(1).docx》，原始题号1—1000。按每编末尾集中答案逐题匹配，完整保留选择题解析和填空题回查定位。训练题库并非官方决赛原题。
- 两套题库均以各自提供的 Word 为唯一题目来源，保留原题、选项、答案、解析或回查定位及原始段落；决赛终稿未逐题标注难度，统一显示“未标注”，未自行生成或修改题目。导入时已校验题量、连续题号、字段和答案格式，并与 Word 原文逐题对照。未逐题独立核验史实，疑似错误需与资料核对。

决赛详细说明：[决赛项目 README](finals/README.md)。

## 功能

- **学习概览**：题库总量、已完成题数、累计作答次数、正确率、待掌握错题、分板块进度及最近考试。
- **顺序刷题**：按原始题号练习，支持板块、题型、难度与关键词搜索、跳题、答题卡、上一题/下一题；提交后立即显示正误、正确答案和原题解析/回查定位。固定底部操作栏，无需滑到页面底部才能切换题目；决赛答题卡按每100题分组。
- **错题本**：错误自动加入，保留累计错误次数、最近错误答案和时间；分为待掌握、已掌握、已移出。重新练习不预选上次答案，答对后标记掌握，再次答错恢复待掌握并累加次数。移出仅隐藏当前列表，可恢复。
- **专项练习与收藏**：支持单独练习筛选后的错题或收藏；本轮题目集合固定，答对后仍可查看。
- **重置练习**：可清除单题的练习答题记录和草稿，保留错误历史和已完成考试快照。
- **模拟考试**：自由设置范围、题型、难度、题量和时长（0分钟表示不限时）；随机抽题不重复，考试期间可修改答案但不显示解析。交卷后展示成绩、题型正确率、用时和逐题分析，并同步错题本。每题等权，总分100分，多选需完全匹配标准答案，决赛填空题支持文字输入，忽略空白、全角字符差异、书名号后与标准答案比对，标准答案为年份时允许省略“年”。不设部分得分，未答题视为错误。
- **计时与恢复**：限时考试截止时间固定；网页打开时到时自动交卷，关闭期间无法执行程序，重新打开后按原截止时间自动补交。
- **数据备份**：在“数据与备份”导出 JSON，包含练习、草稿、错题、收藏、考试和题库修改；校验并确认后可恢复记录。

## 学习记录与隐私

所有个人学习记录均使用 IndexedDB 保存在当前浏览器，不上传到 GitHub，也不提供云端同步。初赛与决赛使用独立数据库；决赛终稿1000题另用新数据库，避免此前版本题目不同导致记录错配。旧记录不被覆盖，但不会在新版中显示；不同版本的备份不能混用。

清除浏览器数据、使用无痕模式或浏览器清理存储可能导致记录丢失，请定期导出 JSON 备份。不同设备、浏览器、开发地址与正式网址的记录通常不能直接共享，可在对应版本中通过备份迁移。

题库文件及代码为公开发布版本，请勿将个人学习备份提交到公开仓库。

## 本地运行

安装 Node.js 22 或更新版本及 pnpm（可通过 `npm install -g pnpm` 安装）。

初赛项目位于仓库根目录，在仓库根目录执行：

```sh
pnpm install
pnpm dev --port 5173
```

打开 http://127.0.0.1:5173/ 。决赛项目位于 `finals/`，在仓库根目录执行：

```sh
cd finals
pnpm install
pnpm dev --port 5198
```

打开 http://127.0.0.1:5198/ 。固定使用相同地址与端口，便于继续使用本地学习记录。

也可在对应项目目录执行 `pnpm build`，然后双击 **启动网站.cmd**（Windows），或运行 `pnpm preview --port 4173` 预览生产构建。

## 编辑和更新题库

1. 在对应网站的“题库管理”搜索题号或关键词，点“编辑题目”。题干、选项、答案、解析、板块、题型和难度均可编辑。
2. “对照Word原文”显示源段落；“恢复Word原题”撤销本题修改。原始 JSON 不受浏览器编辑影响。
3. “导出题库”获得该版本的完整题库，可编辑 JSON 后用“导入更新”批量应用。初赛需包含1—400号题，决赛需包含1—1000号题，题号不得重复，字段和答案须合法。
4. 网页编辑和导入更新仅保存在当前浏览器，可通过 JSON 备份或题库导出迁移。需要更新公开网站的默认题库时，初赛修改 `src/data/questions.json`，决赛修改 `finals/src/data/section-1.json` 至 `section-5.json` 后重新构建。
5. 历次考试保存当时题目快照，后续编辑不会改变历史试卷。请保留 Word 源文与 `rawParagraphs` 以便核对，程序不会擅自纠正原答案。

数据字段：`id` 原始题号，`section` 板块，`type` 题型，`difficulty` 难度，`stem` 题干，`options` 选项，`answer` 答案数组，`answerText` 原答案文本，`explanation` 解析或回查定位，`rawParagraphs` 原始题目与答案段落，`sourceParagraph` Word 题目起始段落（从1起算），决赛终稿另有 `sourceAnswerParagraph` 答案段落。

## Word 导入与校验

在对应项目目录运行（提取工具仅用 Python 标准库）：

```sh
python scripts/import_word.py "对应Word文件的绝对路径.docx"
python scripts/verify_word.py "对应Word文件的绝对路径.docx"
pnpm validate
pnpm test
```

重新导入会覆盖该项目默认题库及导入报告，请先备份。

- 初赛：400题，题号1—400连续无重复；简单169、中等60、较难171。报告：[src/data/import-report.json](src/data/import-report.json)。
- 决赛：1000题，题号1—1000连续无重复；终稿1000题未标注难度；1000题与1000条集中答案逐题匹配，答案及字段完整。报告：[finals/src/data/import-report.json](finals/src/data/import-report.json)。
- 原始段落与 Word 逐题匹配；提取字段可复原源文本的非排版字符。

## 项目结构

```text
src/                             初赛源码
  App.tsx                        页面与交互
  core.ts                       判分、抽题、错题状态、备份验证
  storage.ts                    IndexedDB及保存队列
  style.css                     电脑与手机自适应样式
  data/questions.json           初赛400题
  data/import-report.json       初赛导入报告
scripts/                         初赛 Word 导入、校验与核心测试
finals/                          决赛项目（独立源码及构建配置）
  src/data/section-1.json        党史（1—200）
  src/data/section-2.json        新中国史（201—400）
  src/data/section-3.json        改革开放史（401—600）
  src/data/section-4.json        社会主义发展史（601—800）
  src/data/section-5.json        中华民族史（801—1000）
  src/data/import-report.json    决赛导入报告
  scripts/                      决赛 Word 导入、校验与核心测试
docs/                            GitHub Pages 静态发布目录
  index.html                     初赛入口
  assets/                        初赛发布资源
  finals/                        决赛独立发布目录
    index.html                   决赛入口
    assets/                      决赛发布资源
```

网站没有学习后台、注册模块、跟踪脚本或远程字体依赖，默认开发服务仅绑定本机地址。

## GitHub Pages 发布与更新

仓库使用 `main` 分支的 `/docs` 文件夹作为 GitHub Pages 发布源，包含 `.nojekyll`，两套网站均使用相对资源路径。

**更新初赛**（在仓库根目录运行）：

```sh
pnpm test
pnpm validate
pnpm exec tsc -b
pnpm exec vite build --outDir docs --emptyOutDir false
node scripts/pages-ready.mjs
```

保留 `docs/finals/`。根目录原有的 `pnpm build:pages` 可能在构建时清空整个 `docs/`，所以共用发布目录后请使用上面的保留目录构建命令。

**更新决赛**（在仓库根目录运行）：

```sh
cd finals
pnpm test
pnpm validate
pnpm build:pages
```

将生成的 `finals/docs/` 内容同步到仓库根目录的 `docs/finals/`，不要覆盖根目录的初赛入口和资源。提交对应源码及发布文件到 `main`，GitHub Pages 会自动重新发布。

仓库中 `package.json` 的 `private: true` 仅用于禁止误发布 npm 包，不代表 GitHub 仓库私有。
