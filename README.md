# 五史知识竞赛题库

个人备考用 React + TypeScript + Vite 网站。400道题全部来自《五史知识竞赛题库_word最终版.docx》，不含生成题目。此仓库按所有者要求公开发布到GitHub Pages。个人学习记录仍仅保存在当前浏览器。

在线使用：https://you-sky.github.io/wushijingsai/

仓库：https://github.com/You-Sky/wushijingsai

## 启动

仓库内的 `docs` 文件夹包含可直接发布的构建结果。使用本地版本时先执行 `pnpm install` 和 `pnpm build`，再双击 **启动网站.cmd**，需要已有Node.js。

需要开发或修改源码时，按下述方式启动：

需要 Node.js 22 或更新版本，以及 pnpm（可通过 `npm install -g pnpm` 安装）。在本项目文件夹打开终端：

```sh
pnpm install
pnpm dev --port 5173
```

打开 http://127.0.0.1:5173/ 。固定使用此地址和端口，浏览器才能读取同一份本地学习记录。

生产构建与本地预览：

```sh
pnpm build
pnpm preview --port 4173
```

预览地址为 http://127.0.0.1:4173/ 。开发地址、预览地址、GitHub Pages地址及原私有Sites地址的记录互相独立，可通过备份迁移。手机可直接访问GitHub Pages网址。项目本身无需注册学习账号。

## 使用

- **学习概览**：题库总量、完成数、累计作答数、累计正确率、待掌握错题、分板块进度与最近考试。
- **顺序刷题**：原始题号1—400排列；支持板块、题型、难度与关键词/题号筛选，上一题/下一题、答题卡和跳题。选择答案后点“提交答案”批改。多选必须与标准答案完全一致。
- **错题本**：错误自动加入，保存累计错误次数、最近错误答案与最近作答时间；分为待掌握、已掌握、已移出。重新答对会标记掌握，再次答错会恢复待掌握并累加次数。移出仅隐藏当前列表，可从“已移出”恢复。
- **专项练习**：可练习筛选后的错题或收藏；本轮题目集合固定，答对后不会突然消失。
- **重置练习**：清除某题的练习答题记录和草稿，保留错题历史与已完成考试快照。
- **模拟考试**：设置范围、题型、难度、任意合法题量和0—1440分钟时长（0表示不限时）；同一试卷不重复。考试中可修改答案，交卷后展示全卷分析。每题等权，总分100分，不设部分得分。未答题视为错题。
- **计时与恢复**：考试截止时间固定，切换页面、关闭或刷新不会暂停计时。网页打开时到时自动交卷；网页关闭期间无法执行程序，重新打开时按原截止时间自动补交，用时不会超过设定时长。
- **收藏**：点击题目星标，进入收藏夹后可统一练习。
- **备份**：在“数据与备份”导出JSON，包含全部练习、草稿、错题、收藏、考试和题库修改。导入经过格式校验，确认后替换当前浏览器记录。

所有学习记录使用 IndexedDB 保存在当前浏览器。清除浏览器数据、使用无痕模式或浏览器清理存储可能导致记录丢失，请定期导出。保存失败会在页面提示。系统不提供云端学习记录同步。

## 编辑和更新题库

1. 在“题库管理”搜索题号或关键词，点“编辑题目”。题干、选项、答案、解析、板块、题型和难度均可编辑。
2. “对照Word原文”显示源段落；“恢复Word原题”撤销本题修改。原始JSON不受浏览器编辑影响。
3. “导出题库”获得当前400道题；可以编辑JSON再用“导入更新”批量应用。导入必须包含不同的1—400号题，字段和答案须合法。
4. 网页编辑与导入更新只保存在当前浏览器，可通过JSON备份或题库导出迁移。需要改变项目默认数据时，先备份，再修改 `src/data/questions.json` 并重新构建；请保留Word源文与 `rawParagraphs` 以便核对。
5. 历次考试保存当时题目快照，后续修改题目不会改变历史试卷。原答案疑似有误时请自行核对；程序不会擅自纠正。

数据字段：`id`原始题号，`section`板块，`type`题型，`difficulty`难度，`stem`题干，`options`选项，`answer`答案数组，`answerText`原答案文本，`explanation`解析，`rawParagraphs`原始段落，`sourceParagraph`在Word中的起始段落（1起算）。

## Word导入与校验

Word提取工具仅用Python标准库，可重新执行：

```sh
python scripts/import_word.py "Word文件的绝对路径.docx"
python scripts/verify_word.py "Word文件的绝对路径.docx"
pnpm validate
pnpm test
```

重新导入会覆盖项目中的默认题库与导入报告。源文件SHA256：`074a4b31dbd2531f1ae838fba6d09b232524c368c3b63f21a836238e96dd5bd8`。

校验结果：共400题，题号1—400连续无重复；五个板块各80题，均为单选40、多选20、判断20。简单169题、中等60题、较难171题。未发现重复题干、字段缺失或答案格式异常。逐题原始段落完全匹配；提取字段可复原源文本全部非排版字符。校验只验证提取与结构，不代表对史实进行了外部核验。

## 项目结构

```text
src/App.tsx                  页面与交互
src/core.ts                  判分、抽题、错题状态、备份验证
src/storage.ts               IndexedDB及串行保存队列
src/style.css                电脑与手机自适应样式
src/data/questions.json      唯一默认题库，含Word原始段落
src/data/import-report.json  导入完整性报告
scripts/import_word.py       Word提取器
scripts/verify_word.py       独立原文保真校验
scripts/validate.ts          题库结构检查
scripts/core.test.ts         核心流程自动测试
docs/                        GitHub Pages静态发布文件
```

默认服务仅绑定本机地址。项目没有学习后台、用户注册模块、跟踪脚本或远程字体依赖。仓库与题库现为公开发布版本。个人学习备份不应提交到公开仓库。原Sites站点权限保持不变。

## GitHub Pages发布与更新

发布源为 `main` 分支的 `/docs` 文件夹，内含 `.nojekyll`。访问路径为 `/wushijingsai/`，资源使用相对路径。

更新源码或默认题库后运行：

```sh
pnpm test
pnpm validate
pnpm build:pages
```

将源码及 `docs/` 的构建结果一起提交到 `main`，GitHub Pages会重新发布。仓库中的 `package.json` 的 `private: true` 仅禁止误发布npm包，不代表GitHub仓库私有。
